# J3 Asset Manager JAR distribution

Keep `J3 Asset Manager.jar` and the `libraries` folder together. On Windows, install Java 21 or newer and double-click the JAR to launch the editor. If Windows shows a generic Java error, double-click `Launch J3 Asset Manager.bat` instead. Its console shows the actual error if startup fails.

You can also run this command from this folder:

```powershell
java -jar "J3 Asset Manager.jar"
```

The included JavaFX libraries are for Windows.
