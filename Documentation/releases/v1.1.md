# J3 Asset Manager v1.1

## New features

### J3 Scene Editor

- Assemble scenes from models, groups, lights, and cameras.
- Move, rotate, and scale objects using viewport gizmos and snapping.
- Duplicate objects, organize groups, and frame a selection or the complete scene.
- Add box colliders to scene objects.
- Configure lights, link camera profiles, and preview camera viewing frustums.
- Reload linked models and camera profiles while editing.

### Model and animation workflows

- J3 Model Editor for GLB transforms, materials, and embedded textures.
- Metallic and roughness channel previews and editing.
- J3 animation and script workflows support J3O and GLB model sources.
- Animation Editor imports animation sources, previews clips, and exports selected animations to J3O.
- Animation transfer between J3O files, humanoid rig creation, and posed-model export workflows.
- Blender model import through GLB conversion.
- Texture channel packing, basic texture editing, and PBR map generation tools.

## Fixes and improvements

- Updated GLB loading and editing, preserving binary payloads and unknown chunks when saving.
- Improved packed metallic, roughness, and occlusion texture handling.
- Refined scene selection, transform gizmos, and collider editing.
- Rebuilt application, runtime, GUI, and theme libraries and the Windows launcher for v1.1.

## Java package migration

The former `com.vts` packages have moved to `com.jme`. Update game imports when replacing the libraries:

```java
import com.jme.j3asset.runtime.J3Runtime;
import com.jme.j3asset.runtime.character.J3CharacterRuntime.CharacterInstance;
import com.jme.j3asset.runtime.character.JmeCharacters;
import com.jme.j3asset.runtime.level.LevelSession;
import com.jme.j3asset.core.character.J3CharacterAsset;
```

Maven coordinates use `com.jme.j3asset`. See the updated [runtime integration guide](../getting-started/use-j3runtime.md) for dependencies and examples. Replace the related J3 libraries together to avoid mixing old and new Java packages.
